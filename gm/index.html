Getting started

The app has two workspaces: Rulebooks for PDFs and your sidebar, and Tools for initiative and table aids. The sidebar has Rules, Current, and Search tabs. Your view, theme, open documents, and table tool state are saved in this browser.

Why this app exists

This app is meant to support me as both a player and Game Master of Savage Worlds. I enjoy reading the books and want to keep them central. The challenge is keeping the books and useful details easy to find, so the app brings PDFs, rules notes, campaign notes, and character files together and links them back to the relevant book pages.

I want it to work with character builders such as savaged.us and dicey.cc by importing their data, while leaving validation to those tools. I prefer rolling physical dice, so the dice roller is here for times when I do not have my dice handy. Other tools already handle maps, initiative, and shared online tracking; I may connect more of that later, but for now I focus on the book reference and player-level tracking I enjoy and on features that are not already well served elsewhere.

Search

Use the search box above the sidebar. Results update as you type; searches need at least two characters. Search covers the sidebar’s Rules and Current text, the Reference Index, and searchable text extracted from PDFs.

  • PDF search checks books that are visible in the book tabs by default. Turn on Include hidden books below the search box to include the rest. Reference Index results can be narrowed by type and book using the filters in that result group.
  • The first search in a book may take longer while its PDF text is indexed. Results are grouped by source; select a result to open its page or reveal the matching sidebar text.
  • Search snippets show nearby text, with the matching phrase highlighted where it appears in the snippet.
  • Use the results menu to switch between By source (the default) and By relevance. Relevance favors exact names, then name prefixes and other name matches, aliases, entry types, headings, book/source references, and finally matches in body text. Repeated body-text matches get a small boost. Index results can still be filtered by type and book in either view.
  • Use Collapse all in the results header to fold result groups. Clear the query or press Escape to return to the previous sidebar tab.

Rulebooks and reading

  • Choose Rulebooks, then select a book tab. Page shortcuts and bookmarks are in the navigation strip below the workspace tabs.
  • Use the book-list button (☰) to choose which books appear as tabs. Hidden books can still be opened by links and included in search.
  • Use the navigation-strip toggle (▣ to collapse, ▢ to expand) to show or hide book shortcuts and bookmarks. PDF.js controls provide page navigation, zoom, and presentation options.
  • Select ↗ beside the book-list button to open the current PDF at the current page in your browser’s built-in PDF viewer.
  • Select PDF text and right-click (or long-press on a touch screen) for actions such as bookmarking, copying text or a link, and creating a monster from a stat block.
  • Add a bookmark with the ＋ control in the navigation strip. Give it a useful name; bookmarks are saved in this browser. Links can include a highlighted phrase.

Set up an editable local data folder

Server data is read-only. To edit and keep your own character, monster, and note files, download a copy and connect the extracted folder.

  1. Open the sidebar’s Search tab and choose its data/Markdown tools button (✎), or use Open data management below.
  2. Select Download Data Folder. The app downloads a ZIP containing the current data files. Unzip it to a folder you can keep and back up.
  3. In the same data panel, choose Connect Data Folder and select the unzipped folder containing rules.md, workspace.json, and the characters, monsters, and notes folders.
  4. Grant the browser access when prompted. The connected folder is editable from this browser. Keep the folder in place; if the browser loses access, use Reconnect Folder.

Back up the folder periodically. Changes are written to its Markdown and JSON files. A browser’s local storage also keeps display preferences and table tool state.

Make characters and link them to rules

  1. Connect a writable local data folder, open Current, and choose ＋ Character. The app creates a Markdown file from the character template in characters/ and opens it for editing.
  2. Fill in the character’s details in the editor and save. Use ＋ Open to reopen existing characters, monsters, or notes. Import Character (XML) supports the app’s supported Fantasy Grounds character export.
  3. Link a character file to a PDF rule by adding a wiki link in its Markdown, for example [[swade/58?highlight=Fleet-Footed|Fleet-Footed]]. Replace swade and the page with the book key and displayed page; the label is the text shown in the file.
  4. To put a character into Initiative, open the character file, switch to Tools → Initiative, and choose Import open. A character portrait can be set with the Initiative portrait image path field in the Markdown editor.

Monster files use a Wild Card checkbox: unchecked means an Extra tracked by Count; checked means a Wild Card tracked by Wounds. Monster portraits can also appear in Initiative.

Rules and Current

Rules is your persistent rules reference. Current holds the active character, monster, note, or campaign file. Open documents appear as tabs; drag tabs to reorder them and use × to close a tab. Closing a tab does not delete its file.

The sidebar’s data/Markdown panel (✎) can edit or download Rules, load Markdown, browse documents, manage the data folder, and open the Reference Index. Markdown headings, lists, tables, checkboxes, and PDF links render in the sidebar. In a connected writable folder, edits can be saved to the active file.

In the editor, Link note opens a picker for characters, monsters, and notes, then inserts a link that opens the chosen document in Current. Its Markdown format is [[note:characters/hero.md|Hero]]. Insert image copies a selected image into images/ in your connected data folder and inserts the Markdown at the cursor. Identical image content is reused; a same-name image with different content gets a numbered filename. These actions require a writable local data folder.

Table tools

Open Tools for the initiative tracker and other table aids:

  • Initiative: deal and order Action Cards, track rounds and Jokers, and manage combatant status. Character and monster Shaken, Wounds, and Extra counts connect to their notes.
  • Dice: roll Trait pools with optional Wild Die and acing. Use the 3D tray or Quick roll; choose how multiple dice are evaluated. Themes and sound controls are local to the app.
  • Deck: draw cards separately from Initiative, optionally recording why each card was drawn.
  • Chase: deal cards, move participant tokens with arrows or drag and drop, and refer to maneuver choices and complications. Club cards highlight the relevant complication.
  • Dramatic Task: add participants, deal a card each round, and track task tokens and rounds. The tool shows a complication when a participant draws a Club.

Use the reset button (↻) at the end of the tools tab bar, after Dramatic Task, to clear table tool state. The Initiative panel’s reset button (↻) clears saved table data; similar reset buttons in Chase and Dramatic Task reset those tools.

Use ↗ beside the Tools tab to open Tools in a separate browser window, suitable for another monitor. The pop-out stays connected to initiative notes and shared table state. Use ↙ Return to main window in the pop-out or click ↙ beside the Tools tab to return Tools to its tab.

Reference Index

The index stores searchable rules, names, aliases, and source pages. Open it from the Index button beside the sidebar tabs. Search by name or alias, filter by type or book, and sort by name, type, book, or page. Use the letter buttons to show entries beginning with a specific letter; the list switches to alphabetical order. Types include character options, equipment, status conditions, setting rules, combat rules, modifiers, situational rules, tables, and setting references such as factions, locations, and organizations. Use 🔍 to open the entry in its book, ✎ to edit it, and 🗑 to remove it.

Select 📋 on an entry to copy a link to the clipboard. Paste it into a Rules, Current, or note Markdown file; it uses the app’s [[book/page?highlight=phrase|label]] link format and opens the matching PDF page with the phrase highlighted. You can add entries, import or export an index, and save changes to a writable data folder. Curated index results are also included in sidebar search.

Mobile and display

On a narrow screen, use the sidebar button (☰ to open, × to close) to show or hide the sidebar. Pinch to zoom PDFs; the book/page navigation can be collapsed to leave more room for the document. The theme button cycles through dark, light, and system modes, shown by ☾, ☀, and ◐.

If a PDF crashes or loads slowly, download diagnostics soon after reopening the app. The report includes recent PDF errors and render timings, browser details, and whether each book is cached. It does not include note contents.
